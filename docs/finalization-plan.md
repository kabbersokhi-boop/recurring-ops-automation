reads Task_Master A:J; its employee ID is K. Employee_Queue A:Q stores engine
state and R:U audit metadata. Task_History A:G stores events and H:K audit
metadata. Alert_Log A:K stores reservations and L:Q transport metadata. Settings
A:B stores settings. Manager_Dashboard A:X is generated by the backend.
Overview and friendly derived views can be added without changing these indexes.

accessible cells must remain sanitized. Viewer access supports inspection;
